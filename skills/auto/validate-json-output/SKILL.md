---
name: validate-json-output
description: Use when generating JSON output files from logs or data processing.
---
1. Ensure that all property names in the JSON output are enclosed in double quotes.
2. Validate the JSON structure against the expected schema before saving.
3. Use a JSON linter or validator to check for syntax errors.
4. Self-check the output file to confirm it adheres to the required format and conventions before finalizing.
