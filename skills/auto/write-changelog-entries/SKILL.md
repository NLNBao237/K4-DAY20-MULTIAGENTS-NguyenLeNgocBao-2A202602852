---
name: write-changelog-entries
description: Use when documenting changes made to a codebase in a changelog.
---
1. Record each fix in CHANGELOG.md under the heading '## Unreleased' as a bullet.
2. Ensure each entry follows the format: '- fix(<function name>): <short description>'.
3. Include at least three entries for the changes made.
4. Review the changelog for consistency and completeness before finalizing.
