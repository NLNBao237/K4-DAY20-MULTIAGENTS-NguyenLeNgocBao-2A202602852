---
name: maintain-changelog
description: Use when making changes to the codebase to ensure proper documentation of updates.
---
1. Open the CHANGELOG.md file.
2. Locate the section for '## Unreleased'.
3. For each fix or feature added, write a bullet point in the format: '- fix(<function name>): <short description>'.
4. Ensure that at least three entries are added for recent changes.
5. Check that the entries are clear and concise.
6. Save the changes to the CHANGELOG.md file.
7. Perform a self-check to confirm that the changelog is up-to-date and correctly formatted.
