---
name: check-output-format
description: Use when generating output files to ensure they meet specified format requirements.
---
1. Verify that the output file name matches the required naming convention.
2. Ensure the file format is correct (e.g., JSON, CSV).
3. Check that all required fields are present in the output.
4. Confirm that data types for each field are correct (e.g., integers for counts, strings for names).
5. Validate that any date fields are formatted according to the specified standard (e.g., YYYY-MM-DDTHH:MM:SSZ).
6. Ensure that any monetary values are represented in the correct format (e.g., in cents).
7. Check for any additional required headers or keys in the output.
8. Perform a self-check to confirm that the output adheres to all specified conventions before finalizing.
