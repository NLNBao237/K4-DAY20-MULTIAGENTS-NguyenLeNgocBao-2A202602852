---
name: enforce-type-annotations
description: Use when defining public functions to ensure they include type annotations.
---
1. Review all public functions in the codebase.
2. Ensure that each function has type annotations for all parameters.
3. Verify that the return type of each function is annotated.
4. Check for consistency in type annotations across similar functions.
5. If any function lacks type annotations, add them according to the expected types.
6. Perform a self-check to confirm that all public functions now have complete type annotations.
